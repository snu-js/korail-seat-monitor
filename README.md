# 서울→대전 코레일 취소표 모니터

2026년 9월 23일 18:30 이후 출발하고 9월 24일 19:00까지 도착하는
`서울역 → 대전역`, 성인 1명·일반실 좌석을 약 5분마다 확인합니다.

- 좌석이 새로 생긴 경우에만 GitHub 이슈로 알립니다.
- 같은 좌석 상태가 유지되는 동안에는 중복 알림을 보내지 않습니다.
- 조회가 3회 연속 실패하면 한 번만 장애 알림을 보냅니다.
- 이미 출발한 열차는 제외합니다.
- 9월 24일 19:00(한국시간)이 지나면 워크플로를 자동으로 중지합니다.
- **조회와 알림만 수행하며 예약·결제·취소는 절대 수행하지 않습니다.**

## 1. 코레일 계정 정보를 Secrets에 저장

저장소의 `Settings → Secrets and variables → Actions → New repository secret`에서
아래 두 항목을 만듭니다.

| Name | Value |
|---|---|
| `KORAIL_MEMBER_ID` | 코레일 회원번호, 이메일 또는 휴대폰 번호 |
| `KORAIL_PASSWORD` | 코레일 비밀번호 |

비밀번호를 README, 이슈, 코드, Actions 변수(`Variables`)에 적지 마세요.
반드시 암호화되는 `Repository secrets`에만 저장해야 합니다.

## 2. 처음 한 번 시험 실행

`Actions → 코레일 취소표 모니터 → Run workflow`를 누릅니다. 실행 결과가
초록색 체크이고 로그에 `Checked ... rows`가 보이면 동작 중입니다.

## 3. 아이폰 알림

GitHub Mobile 앱에 `snu-js` 계정으로 로그인하고 GitHub 알림 권한을 허용합니다.
모니터가 좌석을 찾으면 이 저장소에 본인을 지정한 이슈를 만들어 푸시 알림을
발생시킵니다. 소리를 끄고 진동만 사용하려면 아이폰의 GitHub 알림 소리 설정을
꺼 주세요.

## 주의사항

이 프로젝트는 코레일이 공개한 공식 API가 아니라 코레일톡의 읽기 요청을 재현한
오픈소스 라이브러리를 사용합니다. 코레일 측 변경이나 자동화 차단으로 조회가
중단될 수 있으며, 좌석 발견 알림은 좌석 확보를 뜻하지 않습니다. 요청 빈도는
5분에 한 번으로 제한되어 있습니다.
